# POLE-CLaude: fábrica de vídeos Hacoo

Fábrica automática de vídeos checkout de Hacoo (código POLE14).
- `factory.py`: genera vídeos nuevos sin repetir (mira used.json).
- `bank.py`: catálogo de grabaciones (bases), ganchos y frases de voz.
- `engine/`: renderizador (native7.py) y mezcla de audio (mux3.py).
- `recs/`: grabaciones con la dirección tapada.
- `voices/`: frases de voz de Martin Osborne (ElevenLabs).
- `music/`: trozos de las canciones de Pol.
- `TASK.md`: lo que hace la tarea programada.
- `videos/`: vídeos terminados (Metricool los descarga desde aquí).
